# LIBRORA
### Digital Library Management System

LIBRORA is a digital library management system that allows students to explore books, request borrowing, and manage their borrowing activities. Administrators can manage books, students, borrowing requests, and library reports.

**Tagline:** Read • Learn • Grow

## Project Features

- Student Registration and Login
- Admin Authentication
- Browse, Search, and Filter Books
- View Book Details
- Request to Borrow Books
- Manage Borrowing Requests
- Manage Books (CRUD)
- Manage Students
- User Profile Management
- Borrowing History and Book Returns
- Notifications System
- Reports and Analytics
